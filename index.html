01 HOW IT WORKS

Four steps from button
to verified user.

  1. 01

    Add the button

    Place a “Verify with ID.me” button that sends users to the authorize endpoint with your client ID and scope.

  2. 02

    User verifies

    ID.me handles sign-in, multi-factor, and document or database checks. Your app never touches sensitive documents.

  3. 03

    Exchange the code

    Your callback receives a short-lived code. Swap it server-side for an access token and ID token.

  4. 04

    Read attributes

    Call the user info endpoint to confirm verified status and group affiliation, then unlock the right experience.

02 GROUP VERIFICATION

Know the group,

03 QUICKSTART

Exchange the code.
Fetch the user.

Exchange authorization code 
curl -X POST https://api.id.me/oauth/token \
  -d "grant_type=authorization_code" \
  -d "code=AUTH_CODE" \
  -d "redirect_uri=https://yourapp.com/callback" \
  -d "client_id=YOUR_CLIENT_ID" \
  -d "client_secret=YOUR_CLIENT_SECRET"
Fetch verified attributes 
curl https://api.id.me/api/public/v3/attributes.json \
  -H "Authorization: Bearer ACCESS_TOKEN"
Keep your client secret on the server, never in the browser

Endpoints and scopes shown are illustrative. Confirm current values for your integration in the ID.me developer portal.
